# 拾影 v1.7 · 交互调研与设计说明

调研日期：2026-10-10。范围是产品官方说明、开源项目公开介绍和 Android 设计文档；本版实际操作验证使用拾影的专用模拟器。

## 一套连贯的视觉与操作

- 浅暖背景、森林绿主操作、浅绿辅助区域；强化正文与辅助文字的对比度。标题、正文、元信息分别用 21–28、14–17、12–13 sp，使用系统字体，允许系统放大。
- 首页书签标志与手机图标对应。音频、分享、删除、搜索、确认、浏览器、下载和片段库使用同一套圆角线性图案，由本地 Canvas 绘制；音频播放器使用声音主题封面。
- 库记录改为留白充分的圆角内容卡。标题可以显示两行，媒体类型和状态在次级位置；删除保留明确文字，详情中也可删除。
- 视频详情、图文菜单、正文、管理、删除确认、失败信息、播放倍速采用统一底部面板。上方显示内容标题、文件类型、体积与位置，下方先放常用操作，再放复制、来源和删除。长内容可以滚动，关闭按钮、系统返回、面板外点击及拖动顶部把手均可关闭。
- 首页保留既有输入和解析操作。解析视频后增加「只收下声音」卡，说明是原声音频、M4A 文件以及音乐目录；视频与图片仍按原有方式保存在相册。
- 片段库可以按全部、视频、图文、音频筛选，并按标题/作者搜索。空分类与无匹配关键词有明确说明；原有图文仍以整组呈现。
- 按钮采用轻微按压缩放和水波反馈，页面与解析结果用 240 ms 渐入位移，面板用 260 ms 进入、180 ms 退出；关闭系统动画时停用相应效果。动效不阻塞保存任务，也不让列表每次进度更新时重复入场。
- 放大主要触摸目标至至少 48 dp，提供按钮名称与选中状态。小屏及放大字体下让面板正文滚动，避免内容或关键操作被屏幕边缘裁掉。

参考：[Android 可访问性](https://developer.android.com/guide/topics/ui/accessibility/apps)、[Material 3 底部面板](https://m3.material.io/components/bottom-sheets/guidelines)、[Material 字体层级](https://m3.material.io/styles/typography/applying-type)、[Android 动画](https://developer.android.com/develop/ui/views/animations/overview)。

## 声音的真实处理

音频是视频内完整的原声音轨，包含视频本来的音乐、人声和其他声音。AAC 音轨直接取出并封装为 M4A，保留原有压缩数据；其他系统支持的音轨在本机解码为 PCM 再编码为 AAC。B站已有独立声音流时只下载声音流；普通完整视频需要先下载媒体数据再取出声音。图文不展示音频入口。

输出由 MediaStore.Audio 发布到 Music/拾影。音乐文件可以在拾影中播放、暂停、拖动、变速、循环与分享；视频详情中的本地提取复用现有文件。无声音的视频显示明确失败信息，失败或取消不会生成假音频；关闭页面后任务由 DownloadManager 和 JobScheduler 接续处理。

没有引入提取音频的在线服务或麦克风权限。既有视频号链接解析所需的第三方服务沿用此前流程。播放器切后台暂停，未提供后台音乐通知播放。其他格式转码的兼容范围取决于手机系统解码器，当前输出为 M4A。

参考：[MediaExtractor](https://developer.android.com/reference/android/media/MediaExtractor)、[MediaMuxer](https://developer.android.com/reference/android/media/MediaMuxer)、[共享媒体存储](https://developer.android.com/training/data-storage/shared/media)。

## 验证方式

真实链接与已有下载文件验证声音轨道、时长、原始 AAC 数据一致性、后台完成、系统音乐目录、应用内播放及删除。无音轨、PCM 转换和晚到的取消任务使用受控样本验证。网页预览展示的是实际 APK；另外检查片段卡、面板、筛选、搜索、大字体和窄窗口。报告和截图保存在 verification，具体计数以本版报告为准。

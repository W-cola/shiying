# 拾影 · 安卓版 v1.7.0

原生 Android 应用，在手机上解析分享链接、播放视频、预览图文并保存到相册。v1.7.0 保留链接输入和原有视频结果，增加可独立保存的原声音频；同时统一优化片段库、底部面板、图标、文字和动效。沿用浅色与深绿品牌、清空、删除和书签图标。图文归组、多平台解析、视频号在线解析、相册保存、沉浸式全屏和电脑上的真实 APK 预览保留。

## 安装与使用

安装 `dist/拾影-安卓版-v1.7.0.apk`。包名、签名与此前版本相同，可直接覆盖安装，保留原有下载记录及应用内登录会话。适用 Android 8.0 及以上，支持普通 ARM、ARM64、x86、x86_64 安卓手机；不包含原生 CPU 库。

1. 复制手机或电脑端的一条完整分享文字，粘贴到拾影；也可从系统分享菜单发送给拾影。
2. 点「解析视频」。视频可选择网页提供的画质，再点「应用内播放」直接播放；图文点「应用内预览」，在 APK 内左右滑动查看这条链接的全部图片。也有上一张、下一张按钮和张数提示；选中某一张后进入预览，会从这张开始，仍可滑动查看其他图片。
3. 点「保存到手机」。视频保存在 **Movies/拾影**，图片保存在 **Pictures/拾影**，完成后发布到系统媒体库，可在手机相册的「拾影」中查看。图文正文另存为 **下载/拾影** 下的 UTF-8 文本，包含标题、作者和正文。
4. 「我的片段」点视频记录，再点「播放视频」，用同一应用内播放器打开已下载文件。支持暂停、重播、拖动进度、前后跳转 15 秒、倍速和循环。「全屏」隐藏按钮及系统栏，并根据视频尺寸选择方向；「横屏/竖屏」独立切换方向。全屏轻触可显示/隐藏控制，播放时控制在 3 秒后自动隐藏；双击播放/暂停。切到后台暂停，返回恢复此前播放状态。
5. 「我的片段」按一条图文显示，标注已保存的张数；点击即进入同一组图片的滑动预览。右上角「⋯」可查看正文、分享已保存的图片或重新解析。默认保存全部图片，也可选择只保存某一张，此时本次图文记录包含所选图片及正文。
6. 输入框旁的「清空」清除分享文字和解析结果；图文的「删除」确认后移除这一下载批次的全部图片、正文、下载记录和相册条目，进行中的任务也会取消。其他图文、视频和同一链接的另一次下载不受影响。

旧版已经保存在下载目录的文件不会自动迁移；本版的新图片下载才使用 Pictures/拾影。相册展示由系统媒体库和手机相册决定，必要时进入相册的「相册」页查看。

## 应用内播放与电脑预览

解析结果里的视频和下载库里的视频均由私有 `PlayerActivity` 使用 Android 原生播放器播放，不发出外部播放器或浏览器播放 Intent。图片由私有 `ImageActivity` 解码并在 APK 中预览；网页辅助仍用于需要手动登录/验证的解析步骤，系统分享流程保留。

全屏与方向独立管理。以实际解码的宽高为准，竖向视频保持竖屏、横向视频使用横屏，接近正方形的视频保留当前方向；全屏期间还可手动切换方向。进入全屏立即隐藏标题、全部控制按钮、状态栏和导航栏，视频按比例完整显示；轻触画面显示控制，播放中 3 秒后隐藏。暂停、播放结束或错误时显示控制；系统返回键先退出全屏，再返回上一页。切换时保留播放位置，不移除重建视频视图。边缘滑动可临时唤出系统栏。

支持 0.5×、0.75×、1.0×、1.25×、1.5×、2.0×，暂停时改倍速仍保持暂停。「音量亮度」可调播放器音量、静音/恢复声音，以及只在当前播放器生效的亮度，也可恢复跟随系统亮度；没有申请系统设置写入权限。视频区域左右滑动调进度，左半边上下滑动调亮度，右半边上下滑动调音量；有临时数值提示。系统音量键继续控制媒体音量，播放器音量在该音量范围内调整。

普通媒体优先在线播放，保留预检后的有效地址及相应域名的 User-Agent、Referer、Cookie。遇到网络播放器不支持的响应，自动尝试一次应用缓存播放；重试仍在应用内部处理。B站 DASH 的画面和声音、分段媒体会先下载到应用私有缓存，用 Android MediaExtractor/MediaMuxer 合并后播放。页面给出的普通视频号格式参数由既有流式格式处理支持。没有引入播放器登录或额外服务器；编码支持取决于手机系统。

播放预览不会创建系统下载任务、下载记录或相册条目。关闭播放器释放媒体并删除本次缓存，进程异常退出留下的缓存超过 24 小时会在下次在线播放时清理。单次临时输入上限 1 GiB，空间不足或视频较大时提示先保存到手机，再从「我的片段」播放；临时准备与相册保存相互独立。

开发预览已经接入项目专用 Android 15 模拟器。打开 [本机安卓预览](http://127.0.0.1:8787/) 可点击真实 APK 屏幕、拖动/滚轮滑动、操作软键盘、发送整段中文分享文字，测试解析、播放、下载和删除。页面提供用户样本按钮；保存的媒体属于模拟器的相册，可从模拟器桌面的 Photos → Collections/On this device 查看。不会连接或写入你的实体手机。

服务停止后，在项目中双击 `android/启动安卓预览.cmd`，再打开上述地址；在 Codex 中可让助手将此地址打开到右侧浏览器面板。网页中的「停止模拟器」释放模拟器资源，「启动 / 重新连接」恢复同一个设备与应用数据。修改 Java 或资源后点「重新编译并安装 APK」，会自动构建、签名、覆盖安装并回到拾影，安装包也更新到 dist 目录。编译错误写入 `.tmp/preview-build.log`。

网页使用连续截图展示画面，帧率低于原生手机播放；声音由电脑上的安卓模拟器输出，不通过网页音频流传输，需开启电脑音量。横屏与竖屏均保持原始屏幕比例和触摸坐标。关闭网页不会退出服务和模拟器，点击「停止模拟器」可停止设备。

桥接服务仅监听 `127.0.0.1:8787`，使用独立 ADB 端口 5039 和设备 emulator-5580，只接受固定操作、同源请求和每次启动的操作令牌，不提供任意文件或 shell 访问。源码在 `tools/preview_server.py`、`tools/preview.html`、`tools/start_preview.ps1`；Python 标准库运行桥接，Playwright/requests 仅用于开发验证。预览电脑需要项目 Python、SDK、现有 `shiying-test` AVD 和构建工具；这些开发依赖不打入手机 APK。

本机环境已配置好，后续预览直接启动即可。迁移到其他开发电脑时先按下文配置构建工具；仅在尚无 AVD 时运行 `tools/install_test_image.py` 和 `tools/create_test_device.py`。后者使用 `--force` 创建测试设备，已有设备不应重复运行。

## v1.7.0 音频与交互升级

视频解析结果的「只收下声音」卡提供「提取并保存音频」。使用当前选中的视频来源，独立保存 M4A 音频到 **Music/拾影（音乐/拾影）**，不保存第二份公共视频，也不改变原有视频结果、图片保存和解析入口。普通视频会先下载媒体数据到应用临时目录再取出声音；B站有独立声音流时只下载声音。图文不显示声音入口。

「我的片段」中的已保存视频，详情面板提供「提取原声音频」，直接使用已有文件；成功的声音作为独立记录呈现。音频详情支持应用内播放、分享和删除，删除时同步移除实际音频及音乐库条目。音频播放器支持暂停、跳转、拖动进度、倍速与循环；系统媒体暂停键可用，离开页面暂停，不提供后台音乐通知播放。获得/释放音频焦点，并在耳机断开或声音被其他应用抢占时暂停或降低音量。

AAC 直接无损封装为 M4A，原压缩声音数据不重新编码；其他系统支持的音轨本机转换为 AAC。原声包含视频已有的音乐、人声和环境声。没有音轨、受保护音轨或系统不支持的编码会明确失败，不保存空音频。转换缓存上限 1 GiB，任务取消、失败和完成后清理临时文件。音频任务使用现有 DownloadManager/JobScheduler，离开页面仍能完成；不新增麦克风、所有文件访问等权限，也不引入音频提取在线服务。

片段卡升级为圆角内容卡，标题显示两行。详情、图文菜单、管理、删除确认、错误和倍速菜单使用同一套底部面板；显示内容与保存位置，常用操作优先，长内容可滚动。支持关闭按钮、系统返回、点按面板外区域或下滑把手关闭。库中支持全部/视频/图文/音频分类及标题/作者搜索。字体或配置变化后保留搜索、分类、链接结果和画质选择。按钮按压、水波、页面渐入和面板过渡遵循系统动画设置；增强正文/提示文字对比度、主要触摸目标和大字体适配。

市场对照、选择依据与设计细节见 [交互调研与设计说明](DESIGN.md)。本版没有直接引入其他下载器的源码或运行依赖。

## 视频号免登录流程

对于 `https://weixin.qq.com/sph/...` 视频分享链接，直接点解析和保存即可。默认选择兼容性较好的 H.264，也可手动选择页面提供的 H.265；编码类型不代表分辨率高低。

本版使用 [v.mtotech.com 公开解析服务](https://v.mtotech.com/)及其[接口说明](https://v.mtotech.com/skills.md)：一次主动解析提交一次分享链接。请求仅含该链接和普通 HTTP 头，不读、不上传本应用的微信/元宝 Cookie、登录会话、聊天数据或设备身份。解析成功后，视频由系统 DownloadManager 直接从腾讯媒体地址下载到 Movies/拾影。服务不是微信官方 API，也不是轻抖；本版没有接入轻抖账号或内部接口。

使用该功能意味着分享链接会发送给第三方服务。接口可用性和媒体地址有效期由服务及上游决定，不能保证永久免费可用或所有视频都成功；遇到失败或地址过期，可重新主动解析。HTTP 429 时等待后再操作。本版没有自动注册、付费、登录、安装证书或修改系统代理。

当前公开服务的图集字段尚未验证，sph 在线服务按单个视频处理；视频号其他网页的明确图片列表仍由既有网页解析器处理。

## 网页辅助与下载

普通网页未直接提供内容时，支持进入原有的「浏览器辅助解析」。需要登录或验证码时由使用者手动完成，并打开原来的目标内容。视频播放后点「读取」，图片打开详情后读取。应用仅使用该页面正常提供的状态、目标接口响应或播放器数据，严格匹配目标内容编号，避免下载推荐内容、封面或加载动画。链接参数保留用于访问原网页，不会导出到正文文件。

B站常见的视频、声音分离文件由 Android DownloadManager 分别下载，再通过系统 MediaExtractor/MediaMuxer 无损合并成一个带声音的 MP4。完整 MP4 可直接保存；兼容的 MP4 分段也支持合并。视频号某些正常播放格式使用网页明确提供的播放参数处理文件头，完成后检查视频轨道并写入相册。手机无需安装 FFmpeg。

系统下载可在应用切换后继续；原生合并任务通过 JobScheduler 持久调度，支持重新打开应用和设备重启后的恢复。手动强行停止应用、厂商后台限制、网络中断或下载地址过期仍可能影响完成，重新打开应用可查看状态。失败任务清理其临时媒体片段；删除未完成任务会取消所有对应片段和合并任务。

只选择页面实际提供的画质。不额外去水印，不保证原画或所有内容可解析。直播、批量主页/合集、DRM、付费权限之外的内容、FLV 分段以及通用 HLS 清单暂不支持。B站支持的是其已取得的视频/音频文件流，不代表对所有网站的 DASH 清单提供通用支持。登录、验证、删除、地区限制和链接失效仍需以平台实际访问状态为准。

## 权限与数据

需要联网和重启后恢复下载的普通权限。Android 8–9 首次保存到公共媒体目录需要存储权限；Android 10 及以上使用系统 DownloadManager 和 MediaStore，无需所有文件访问权限。音频通过 MediaStore.Audio 写入 Music/拾影，Android 10 以上操作本应用自己创建的音频不申请读取其他音乐文件的权限。不申请通讯录、相机、麦克风、定位或安装其他应用的权限。

只在点击「粘贴」时读取剪贴板。视频号 sph 链接会提交给前述第三方在线服务；记录、网页会话及未完成的播放参数保存在应用本地；成功完成或取消后清除视频号播放参数。关闭了应用数据备份，没有广告、分析统计或云端同步。「我的片段 → 管理」可清除浏览器会话。请下载自己拥有或已获授权的内容。

## 构建与源码

`app/src/main/java/` 为原生 Java 源码；`app/src/main/assets/` 包含 WebView 的页面读取脚本。界面使用 Android View、Canvas 和 WebView；网络使用 HttpURLConnection 和按域隔离的 Cookie。没有运行时第三方依赖。

用 Android Studio 打开此目录，可按 Gradle 构建（AGP 8.7.3，Gradle 8.9，JDK 17 或 21）。也可配置已有 JDK 和 SDK 后，在项目根目录运行：

```powershell
$env:SHIYING_JDK = '你的 JDK 目录'
$env:SHIYING_SDK = '你的 Android SDK 目录'
.\.venv\Scripts\python.exe android\tools\build_apk.py
```

命令行工具使用 Platform 35 / Build Tools 35.0.1，执行 AAPT2、javac、D8、zipalign、APK v2/v3 签名和签名验证。Windows 中文路径可用 `SHIYING_BUILD_ROOT` 指向同一项目的英文入口。版本为 1.7.0 / versionCode 11。命令行构建先清除构建目录内的旧 class/dex 文件，避免播放器重构后的旧内部类残留。

原有本地签名密钥位于项目根目录 `.android-build/private/`，不包含在源码包或 APK 中。保留此目录才能继续生成能覆盖安装的版本，不要分享密钥或密码。源码 ZIP 不含 SDK、网页会话、带签名参数的网页响应、签名密钥及密码、测试 MP4 或运行日志。

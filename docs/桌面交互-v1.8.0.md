# 桌面交互 v1.8.0

以现有 Android 能力为依据，优化 Windows Qt 客户端。未改动 Android 源码或 APK。

## 从手机版移植

- `android/app/src/main/java/cn/shiying/mobile/core/VideoResolver.java`：Android UA 展开短链，按内容编号读取分享页，必要时从目标页读取媒体。
- `android/app/src/main/assets/browser_capture.js` 与 `browser_read.js`：目标内容的网络 JSON、公开状态、可见播放器组件媒体数据。桌面副本逐字相同，测试防止漂移；打包时作为资源携带。
- `android/app/src/main/java/cn/shiying/mobile/PlayerSource.java`：直接媒体优先流式播放；复合或不兼容媒体转临时缓存。桌面用仅绑定选定源的本机 Range 转发保留请求头，预览任务独立于解析/保存任务。
- 请求代次、取消和过期结果丢弃：更换链接或画质后，旧图片或后台媒体不会覆盖新内容；关闭窗口等待 Qt 后台任务完成清理。

## 速度与无水印约束

自动浏览器无需下载视频、封面、字体，也不等待整页 DOMContentLoaded。网络响应完整到达后再处理 JSON；首个匹配目标且可用的播放源即可返回。

无水印要求优先于最快返回：不采用平台分享下载水印版作为回退，图文优先原图并排除显式水印处理地址。仅凭 URL/元数据不能识别作者已经烧录进像素的标识；本版本未声称具有通用图像去水印或像素级水印检测能力。

实测记录保留旧版约 23.89 秒基准及最终无水印解析/首帧耗时。早期一次 0.88 秒解析返回的是之后已剔除的分享下载版本，不计入最终无水印性能。数值受网站、会话及网络影响，不承诺固定秒数。

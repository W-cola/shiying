# 桌面离线文案 v1.9.0

本轮核对了本机新版安卓工作区的 SpeechRecognizer、模型清单、连续阅读和文案资料库实现。桌面之前只移植了主目录的旧版下载与原声导出，遗漏了新版手机端的离线识别。本次补入桌面；没有覆盖或重置手机端工作区。

## 入口与阅读

- 分享链接解析结果：「提取视频文案」。只准备音轨，不产生一条下载历史。
- 我的片段：选择视频或音频，点击「提取文案」。
- 原声文案：导入本地音频或视频，按标题及识别全文搜索。
- 连续正文、独立滚动、底部回听与复制；修改保存原稿，支持恢复原文、导出 TXT。
- 选中文字依据模型真实字词时间戳回听，到范围末尾停止；没有字词时使用原始讲话段范围。编辑后的全文不构造虚假对齐。
- 手动滚动不被自动跟随抢回，按「回到播放处」恢复跟随。倍速在回听条；整理与删除收在更多菜单。
- 暂停保存已完成段落；应用关闭先停止后台任务，重启可从检查点继续。重新识别另存新稿，旧稿保留。

Qt 原生组件参考本地 open-claude-ui 提交 `02d021fceaf2a907f9e63a8125621bdda1b85d60` 的 `CdsButton.tsx` 按钮层级及 `useClaudeScrollPinning.ts` 用户滚动优先原则，适配现有绿色品牌，没有引入 React，也没有复制其源码。

## 离线与缓存

sherpa-onnx 1.13.8 + SenseVoice Small int8 2024-07-17 + Silero VAD，与新版安卓模型一致，合计 240,193,589 字节。采用两个 CPU 推理线程，FFmpeg 解码为单声道 16 kHz，VAD 分段且每段保存一次。单段最长约 20 秒；取消在当前短段推理结束后响应。音频缓存上限 512 MiB PCM，超限明确失败。

主模型首次下载使用模型清单中的固定版本国内镜像，失败切换官方源；支持 HTTP Range 续传。离线导入 ZIP 只接受清单中的三个文件与可选清单，拒绝多余路径、不完整、重复或损坏文件。识别前重新验证全部 SHA256，不能只凭文件名或大小启用。

可用 `tools/package_speech_model.py --models <三个模型文件所在目录>` 生成离线 ZIP。便携版不含 239 MB 主模型和用户数据，源码只含固定清单及不足 1 MB 的支持模型。识别音轨不发送给在线服务，分享视频的来源下载与识别包下载仍需要网络。

文案及回听副本独立于收藏媒体。删除文案只清理它的私有目录；删除媒体不清理文案。识别中的文案不可删除或修改，避免迟到的识别结果恢复已删除内容。

## Windows 图标

程序提供 16–256 px 九档 Qt 位图图标，同时给真实 HWND 发送大、小 `WM_SETICON` 并设置窗口类图标。每个主窗口/播放器设置明确的 AppUserModelID、重启命令、显示名称和 `.ico` 重启图标；重启属性先于 ID 设置，要求任务栏刷新分组图标。没有删除全局图标缓存或重启资源管理器。

`--verify-ui --report` 会读回真实原生图标句柄、Qt 尺寸列表及 Windows 窗口属性，单独验证运行时绑定，不再只检查 EXE 内资源和桌面快捷方式。

## 验证边界

自动回归覆盖模型摘要、ZIP 路径和损坏拒绝、下载续传、独立文案数据、编辑恢复、全文搜索、真实时间范围和桌面入口。另以官方真实中文 WAV 完成禁用 HTTP 的识别、分段暂停恢复、无声拒绝、实际 Qt 解码回听及选区边界停止。短录音的耗时不能代表长视频或所有设备；人名、近音字、方言、歌曲和重叠讲话仍需回听校对。

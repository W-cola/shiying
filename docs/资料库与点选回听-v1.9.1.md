# 资料库与点选回听 v1.9.1

原界面把「我的片段」和「原声文案」列成并列导航，视频与从它提取的文字分散在两处。现在侧栏保留「收下内容」与「资料库」，资料库按原始内容组织，文案作为同一内容的阅读入口。

## 资料库

- 「全部 / 视频 / 图文 / 音频」直接显示为筛选按钮，取消下拉选择。
- 「有文案」是可叠加条件，例如只看有文案的视频，而不是把文案当成另一种媒体类型。
- 按原始文件路径或分享地址关联文案，新稿保留在同一内容下。历史记录仍然按原保存批次管理，不修改或删除现有 JSON 与媒体。
- 搜索同时查找内容标题、作者及文案全文。阅读页返回资料库时保留筛选、关键词和选择项。
- 已删除媒体的文案仍会作为独立内容显示；有原文件时可播放，没有原文件时仍可阅读文字、回听文案缓存。删除媒体不删除文案。
- 选择条目后提供播放、阅读文案与提取新稿；管理操作在更多菜单中。

## 点选与播放

对照本机新版安卓 `TranscriptReader.java`、`TranscriptActivity.selectParagraph()` 与 `SpeechText.java`：手机版短按正文先定位选段，再通过回听按钮播放。桌面适配鼠标的点选和拖选：

- 单击文字先定位到该字词真实时间；暂停时按「从此处播放」开始，正在播放时点文字会直接跳转并继续。
- 拖选保持系统原生文本选择，回听选区在对应末尾停止。双击可以选词，Shift 选择与编辑状态不触发新的点选；空白区域不定位。
- 按 UTF-16 光标位置与原始识别文本对应，处理中文、表情、自动换行及滚动后的命中位置。
- 有字词时间用真实字词时间；旧文案无字词时间则退回原讲话段起点。不按字数均分时间。修改后的全文无法精确对齐时明确提示，可恢复原稿继续点选。
- 回听高亮优先显示当前句及字词，避免将整个长讲话段同时铺成高亮。手动滚动仍优先，不被自动跟随抢回。

界面继续使用已有绿色主题与 Qt 原生控件，沿用 open-claude-ui 的按钮层级、渐进显示管理操作及用户滚动优先原则；没有引入新框架或复制组件源码。

## 验证

回归检查覆盖正文实际单击、拖选、双击、空白命中、编辑模式、真实音轨的点选起播与播放中跳转、选区末尾停止、旧时间范围和 UTF-16，以及内容文案关联、全文筛选、返回状态和删除媒体后的文案保留。另以本机现有 1228 字文案的只读副本，验证换行、滚动后点击约 2:16 的真实时间点，并实际回听；副本与报告仅保存在 `.tmp/`，不上传用户文案和音视频。

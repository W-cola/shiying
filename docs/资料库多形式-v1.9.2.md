# 资料库多形式入口 v1.9.2

## 问题与行为

同一条视频有文案时，旧界面将播放、阅读入口放在远离条目的底部；勾选「有文案」还会把双击视频改为阅读文案，用户无法预期。现在筛选只改变列表，双击始终优先打开主媒体，每条内容旁直接显示实际可用的「看视频 / 看图文 / 听原声 / 读文案」。右键及条目末尾「···」提供相同的打开方式，提取与文件管理位于分隔线之后。

同一形式有多份时显示数量，按钮及右键菜单均可选择具体版本；文案按创建时间从新到旧排列。右键作用于鼠标所在条目，菜单回调绑定具体文件，避免操作之前选中的另一条记录。切换形式时关闭之前的预览并暂停其他播放。纯音频播放器使用紧凑窗口，控制条常显，不出现全屏、旋转与亮度。

## 关联与兼容

- 相同来源链接、相同本地路径的保存记录组合为一条内容，各份原始记录保留。
- 提取原声记录增加可选 `origin_path`，与来源视频及其文案保持关联；旧记录不重写。
- 文案通过原始文件、来源链接及旧文案的回听缓存关系关联；多个文案保留，最新在前。
- 只显示真实存在的媒体入口；原声优先使用已保存音频，否则使用文案的本地 `audio.m4a`。原视频丢失时明确提示，已有文案和原声仍可打开。
- 音频筛选也能找到有原声回听的内容。「有文案」不会改变双击视频的行为。
- 删除只针对用户选择的一份保存记录及其文件，不连带删除其他形式、文案或回听缓存；原来的删除确认继续保留。
